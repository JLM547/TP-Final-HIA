# Backups y Respaldo de Configuración

Esta carpeta contiene los respaldos de configuración y datos del proyecto.

## Contenido

- **Backups de Base de Datos**: Exports de MongoDB
- **Backups de Configuración**: Archivos de configuración de Docker, servicios, etc.
- **Snapshots**: Capturas del estado del sistema en diferentes momentos

## Frecuencia de Backup

Los backups se generan automáticamente según la configuración del sistema.
