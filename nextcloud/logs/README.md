# Logs y Registros del Proyecto

Esta carpeta contiene los registros y logs del sistema.

## Tipos de Logs

- **Logs de Aplicación**: Logs del backend y frontend
- **Logs de Base de Datos**: Logs de MongoDB
- **Logs de Docker**: Logs de contenedores
- **Logs de Monitoreo**: Logs de Prometheus y Grafana
- **Logs de Acceso**: Registros de acceso y seguridad

## Rotación de Logs

Los logs se rotan automáticamente para evitar el consumo excesivo de espacio.
